# `dpmxl.dpm`

Export modules of an EBA DPM 2.0 database to module files.
[`open_release`][dpmxl.dpm.open_release] takes a SQLite file, the EBA's
Access file or the ZIP file the EBA publishes it in. See
[Start from an EBA DPM release](../../guides/from-a-dpm-release.md).
