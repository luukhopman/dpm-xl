# `dpmxl.xbrl`

Evaluates a [module's](../module-file.md) rules on an XBRL report read with dpm-xbrl. Needs the `xbrl` extra: `pip install "dpm-xl[xbrl]"`. See [Check an XBRL report](../../guides/end-to-end.md).
